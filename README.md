# 优学东方 · 原版教研助手

面向机构内部 30-40 名英语教师的 PU / Think 教研与师训助手。先在本地电脑运行,同一 WiFi 下的手机和电脑都能用;以后可以部署到云服务器,或迁移到扣子(Coze)。

## 一、能做什么

1. 对话:按你们的系统提示词工作,支持全部指令(菜单、答疑、备课、分层、衔接、做培训、评课、诊断、体系、家长话术、查一下、提交、学习这份、简版、展开),手机上也能直接用。
2. 四级知识库:L1 机构标准 / L2 官方依据 / L3 课例参考 / L4 参考资料。每次提问先检索,结果按可信度排序、带层级标签交给模型,模型据此标注(机构标准)(官方依据)等出处。
3. 联网搜索:接博查搜索后,模型遇到中考说明、政策、教材版本等时效问题会先搜索再答,并注明来源和日期;没接时自动写"未检索到,需人工核实"。
4. 附件:评课材料、待学习资料可直接上传(docx / pdf / pptx / xlsx / txt / md)。
5. 隐私:手机号、身份证号在发给模型前自动替换为"[已隐去]"。
6. 入库卡闭环:模型生成入库卡后,老师一键提交;教研负责人在后台修改、审核,通过后自动写入知识库。
7. 下载 Word:教案、培训方案等较长的回答可一键下载为 Word,直接打印或修改。
8. 回答反馈:老师对每条回答点 👍/👎(可写哪里不对),教研负责人在后台集中查看差评,针对性补资料、改提示词。
9. 管理后台:批量建账号、上传资料、检索测试、知识缺口统计(回答里出现"知识缺口:…"会自动汇总)、回答反馈、使用统计、导出扣子知识库。

## 二、快速开始(Windows)

1. 安装 Python 3.10 或以上版本(python.org 下载,安装时勾选 "Add Python to PATH")。
2. 下载本项目,双击 `start.bat`。第一次会自动安装依赖(几分钟),并生成 `.env` 配置文件。
3. 浏览器打开 http://127.0.0.1:8000 。管理员账号是 `admin`,初始密码打印在启动窗口里(也可以先在 `.env` 的 `ADMIN_PASSWORD` 里设好)。
4. 没填大模型密钥时是"演示模式":只返回知识库检索结果,方便先把资料传上去检查。

Mac / Linux 运行 `./start.sh`。手动方式:`pip install -r requirements.txt`,再运行 `python run.py`。

## 三、接入大模型(必做)

用记事本打开 `.env`,填三项后重启程序:

LLM_BASE_URL | 接口地址
LLM_API_KEY | 密钥
LLM_MODEL | 模型 ID

推荐豆包(火山方舟):和扣子是同一家,以后迁移效果最接近。在火山方舟控制台创建 API Key、开通模型。`.env.example` 已预填 2026 年 10 月方舟在售的 `doubao-seed-2-1-pro-260915`(更快更省可换 `doubao-seed-2-1-lite-260915`),模型 ID 会随版本更新,以方舟文档"模型列表"为准。也可以用 DeepSeek 或通义千问,`.env.example` 里有现成写法。

豆包 2.x 默认开启"深度思考":对你们这份规则很多的提示词遵守得更好,但每次回答前要多等一会儿(界面会显示"深度思考中……")。老师嫌慢时,在 `.env` 里取消 `LLM_EXTRA_BODY` 那一行的注释即可关闭。

建议同时开通向量模型,填到 `EMBED_MODEL`(默认复用上面的地址和密钥)。豆包目前提供的是多模态向量模型 `doubao-embedding-vision-251215`,程序会自动走它的专用接口并加上官方推荐的检索指令。不填也能用,但只能按关键词检索,换个说法就可能搜不到。

费用按各平台的按量计费,以平台价格页为准。可以用 `DAILY_MESSAGE_LIMIT` 限制每人每天的提问次数。

## 四、接入联网搜索(建议)

到博查开放平台(open.bocha.cn)注册,在"API KEY 管理"拿到密钥并充值,然后在 `.env` 设置:

SEARCH_PROVIDER=bocha
SEARCH_API_KEY=你的密钥

余额不足、密钥错误、请求过频时,回答里会显示具体原因。默认 `SEARCH_MODE=tool`,由模型判断什么时候搜。如果所用模型不支持工具调用(function calling),改成 `LLM_SUPPORTS_TOOLS=false` 和 `SEARCH_MODE=auto`:问题里出现"中考、政策、最新、查一下"等词时,程序先搜索再回答。

## 五、让同事访问

1. 启动窗口会显示"局域网访问: http://192.168.x.x:8000",同一 WiFi 下的手机和电脑打开这个地址即可。
2. Windows 第一次运行会弹防火墙提示,选"允许访问"。
3. 运行程序的电脑不能关机或睡眠。长期使用建议上云(见第八节)。
4. 管理后台 → 账号 → 批量新建,每行一个"用户名,姓名,初始密码,教师"。老师第一次登录会被要求改密码。

## 六、建知识库

先读 `templates/资料整理规范.md`,要点如下:

1. 教材做成"单元卡"再上传(模板:`templates/单元卡模板.md`),不要上传整本教材和教参,这样版权风险小、检索准、模型也不会编页码。
2. 每张卡、每条标准之间用单独一行 `===分段===` 隔开,检索能精确命中。
3. L1 只放教研负责人确认过的内容(模板:`templates/机构标准示例.md`)。
4. 扫描版 PDF 需要先 OCR 成文字版。
5. 批量导入:把资料放进 `资料/L1`、`资料/L2`、`资料/L3`、`资料/L4` 四个文件夹,运行
   `python scripts/import_folder.py 资料`(Windows:`.venv\Scripts\python scripts\import_folder.py 资料`)。
6. 上传后到后台"检索测试",输入老师可能会问的问题,看能不能搜到对的资料。

上线前最少准备:当年常州中考英语考试说明、最先开班级别的单元卡、确认版分层规则、10-20 条常见问题标准答案、3-5 个优秀课例。

## 七、日常管理

1. 修改提示词:直接编辑 `prompts/system_prompt.md`,保存后下一次提问就生效,不用重启。
2. 入库卡:后台"入库卡审核",可以改内容、选归入 L1/L3/L4,通过后自动入库,并填写状态和审核意见。
3. 知识缺口:后台"知识缺口"按出现次数排序,按顺序补资料。
4. 回答反馈:后台"回答反馈"看老师点 👎 的回答和原因,常见问题是缺资料(补知识库)或规则没遵守(改提示词)。
5. 备份:整个 `data/` 目录就是全部数据(数据库加上传的原文件),定期复制一份即可。
6. 改了 `.env` 需要重启程序。

## 八、部署到云服务器

1. 买一台云服务器(2核4G 够 30-40 人用),安装 Docker。
2. 上传项目目录,配置好 `.env`,运行 `docker compose up -d`。
3. 浏览器访问 `http://服务器IP:8000`。如果要用域名和 HTTPS(接扣子插件必须有),境内服务器需要先完成 ICP 备案,再用 Nginx 等反向代理配置证书。反向代理要关闭缓冲(`proxy_buffering off`),否则回答不会逐字显示。
4. 本地已有的数据:把本地 `data/` 目录复制到服务器项目目录下即可。

## 九、迁移到扣子

见 `coze/迁移指南.md`。两条路线:

1. 全部搬到扣子:后台一键导出知识库 zip(已按扣子自定义分段格式整理,带层级标签),把提示词粘进扣子人设。
2. 扣子负责对话,知识库留在自己服务器:用 `coze/kb_plugin_openapi.yaml` 在扣子创建插件,`.env` 设置 `PLUGIN_API_KEY` 即可开启接口。

指南末尾附有 8 条上线验收问题,迁移前后都可以用它们检查效果。

## 十、目录结构

app/ | 后端(FastAPI):对话、检索、账号、后台接口
prompts/system_prompt.md | 系统提示词(你们写的完整版)
prompts/runtime_rules.md | 程序自动追加的运行时说明(日期、检索结果格式等)
static/ | 网页(聊天页、管理后台)
templates/ | 单元卡、入库卡、机构标准模板和资料整理规范
scripts/ | 批量导入、导出扣子知识库
coze/ | 扣子迁移指南和插件定义
tests/ | 自动化测试(`python -m pytest`)
data/ | 运行后生成:数据库和上传文件(不进 git)

## 十一、常见问题

1. 回答说"知识库暂无此项":到后台"检索测试"用同样的问题试,搜不到就说明缺资料或文件名、内容里没有相关说法。
2. 回答不逐字显示:检查反向代理是否关闭了缓冲。
3. 报"模型接口返回 401":密钥错误;"404":模型 ID 或接口地址错误。
4. 换了向量模型后检索变差或报维度不一致:后台"知识库"点"全部重建向量"。
5. 老师忘记密码:后台"账号"里重置,对方下次登录时会被要求修改。
6. 在微信里打开点"下载Word"没反应:微信内置浏览器不支持下载,点右上角"…"选"在浏览器打开"。
7. 联网搜索报"余额不足":到 open.bocha.cn 充值;报"API KEY 无效":检查 `SEARCH_API_KEY`。
