# 资料整理与入库规范

## 一、四个库放什么

L1 机构标准库 | 教研负责人确认的标准、SOP、分层规则、衔接映射定稿、FAQ 标准答案 | 只有管理员能放,每条写确认人和日期
L2 教材官方库 | PU、Think 单元卡,官方课程大纲摘要,课程标准摘要,常州中考考试说明 | 教材请整理成单元卡,不要整本上传
L3 课例库 | 审核过的优秀课例、教学设计、听课记录 | 老师在对话中生成入库卡,管理员审核后入库
L4 参考资料库 | 网上收集、购买的各类资料,质量未统一审核 | 只能当素材,不能当结论依据

## 二、为什么教材要做成"单元卡"

1. 版权:整本教材、教参、付费资料原文放进知识库,模型更容易大段输出原文。单元卡是机构自己整理的概要,风险小很多。
2. 检索准确:一个单元一段,老师问"PU 3 Unit 5"时能精确命中,不会被大段无关文字稀释。
3. 防止编造:系统提示词要求"单元卡里没有的页码一律不写",单元卡写得越准,回答越可靠。

模板见 templates/单元卡模板.md。建议先做最常用的 1-2 个级别,验证效果后再铺开。

## 三、文件格式要求

1. 支持 txt / md / docx / pdf / pptx / xlsx。老版 .doc/.ppt/.xls 先另存为新格式。
2. 扫描版 PDF(图片)读不出文字,需先用 OCR 工具(如 WPS、微信"提取文字")转成文字版。
3. 文件名会显示在回答的引用里,请起有意义的名字:[库名]_[PU/Think/通用]_[级别或年级]_[主题]_[YYYYMMDD]。
4. 一个文件只放一个主题。课例集合可以放一个文件,但每个课例之间用单独一行 ===分段=== 隔开。

## 四、批量导入

把资料按层级放进四个文件夹:

资料/L1/ … 机构标准
资料/L2/ … 单元卡、课标、考试说明
资料/L3/ … 课例
资料/L4/ … 参考资料

然后在程序目录运行:
python scripts/import_folder.py 资料
(Windows 用 .venv\Scripts\python scripts\import_folder.py 资料)

## 五、上线前的最小资料包(建议优先准备)

1. 常州中考英语考试说明(当年版,L2)
2. 你们最先开班的 PU、Think 级别的单元卡(L2)
3. 分层分班规则、跨级调整规则的确认版(L1,未确认前不要放 L1)
4. 老师最常问的 10-20 个问题的标准答案(L1)
5. 3-5 个公认的优秀课例(L3)

上线后在管理后台"知识缺口"页查看高频缺口,按次数补充资料。
